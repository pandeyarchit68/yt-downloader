About This Project

What is YT Downloader?

A lightweight, self-hosted tool to download YouTube videos and audio — privately, with no tracking.

🔒

100% Private

Everything runs on your own machine. No data is sent to any third-party server. Your downloads stay yours.

⚡

Powered by yt-dlp

Under the hood, this tool uses yt-dlp — the most actively maintained YouTube downloader available. It supports thousands of sites and formats.

🎛️

Full Control

Choose your format (video, audio, or both), resolution (up to 4K), and optionally embed English subtitles — all from a clean interface.

🛠️

Built With

  • • Python + Flask — backend server
  • • yt-dlp — download engine
  • • Tailwind CSS — styling
  • • ffmpeg — audio/video processing
