Frequently Asked Questions

Got Questions?

Everything you need to know about using YT Downloader.

Is this tool free to use? ▾
Yes, completely free. It's a self-hosted tool — you run it on your own machine at no cost.
What formats can I download? ▾
You can download video + audio (best quality merged), video only, or audio only as MP3. Resolutions range from 360p up to 4K.
Why isn't my video downloading? ▾
A few common reasons:
  • The video is age-restricted or private
  • yt-dlp needs an update — run pip install -U yt-dlp
  • ffmpeg is not installed or not in your PATH
  • The URL is malformed — make sure it's a valid YouTube link
Does it work with YouTube Shorts or Playlists? ▾
YouTube Shorts work just like regular videos. Playlist support depends on your backend configuration — by default, only the first video in a playlist URL is downloaded.
Where are my downloaded files saved? ▾
Files are saved to the downloads/ folder in the project directory by default. You can change this in app.py.
Is it legal to download YouTube videos? ▾
Downloading videos for personal, offline use is a grey area that varies by country. You should only download content you own or have permission to download. Never redistribute copyrighted material.
